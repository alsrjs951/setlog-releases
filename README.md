# SetLog Android Releases

개인용 한국어 운동 기록 앱의 서명된 Android 설치 파일을 제공합니다. 등록된 소유자 Google 계정만 데이터를 이용할 수 있습니다.

- [웹앱](https://setlog-f5408.web.app)
- [최신 APK](https://github.com/alsrjs951/setlog-releases/releases/latest/download/SetLog.apk)
- Android 7 이상. Google Play 서비스가 있는 갤럭시에서 사용합니다.

## 설치

APK를 다운로드해 열고 설치합니다. 업데이트할 때는 기존 앱을 삭제하지 않고 새 APK를 설치합니다. 로그인 후 설정에서 알림 및 정확한 알람 권한을 허용하세요. 소리와 진동은 시스템 알람 볼륨과 알림 채널 설정을 따릅니다.

## 검증 범위

서명, 빌드, 자동 테스트를 확인했습니다. 실제 갤럭시의 잠금 화면·절전 상태에서 휴식 알림이 도착하는지는 별도 확인이 필요합니다.

이 저장소에는 설치 파일과 안내만 포함됩니다. 운동 기록, 서버 관리 인증 정보, APK 서명키는 포함하지 않습니다.
